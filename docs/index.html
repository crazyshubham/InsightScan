How It Works

A four-stage automated pipeline

Each script does exactly one job. Together they go from a URL list to a fully analyzed Excel report.

01
scraper.py

Scrape

Visits each URL with browser-like headers, finds the article title inside <h1> and body inside WordPress content divs using BeautifulSoup. Saves each article as a .txt file.

requests.Session BeautifulSoup 82 URLs
02
sentiment.py

Score Sentiment

Tokenizes text, removes 7 categories of stopwords, then counts matches against master positive and negative dictionaries. Computes polarity and subjectivity scores using the Loughran-McDonald methodology.

NLTK Lexicon-based 4 scores
03
readability.py

Measure Readability

Computes the Gunning Fog Index, syllable counts, complex word ratio, sentence length, personal pronoun usage, and average word length using NLP formulas on cleaned token lists.

Fog Index Syllables 9 metrics
04
main.py

Export to Excel

Orchestrates the full pipeline. Reads Input.xlsx, loads each article, calls both analysis modules, collects 15 columns of results per row, and writes the complete Output.xlsx with pandas.

pandas openpyxl Output.xlsx
Output Structure

15 columns. Every one intentional.

The final Output.xlsx contains every article mapped to a full set of NLP metrics — four sentiment scores and nine readability indicators.

Sentiment Analysis
POSITIVE SCORE
Count of positive words matched against the master dictionary after stopword removal.
Σ(words ∩ positive_dict)
NEGATIVE SCORE
Count of negative words. Reported as a positive number for consistent output.
Σ(words ∩ negative_dict)
POLARITY SCORE
Direction of sentiment. Range −1 (very negative) to +1 (very positive).
(Pos − Neg) / (Pos + Neg + ε)
SUBJECTIVITY SCORE
How opinion-based the text is. 0 = objective. 1 = highly subjective.
(Pos + Neg) / (Total + ε)
Readability Metrics
AVG SENTENCE LENGTH
Total words divided by total sentences.
words / sentences
COMPLEX WORD COUNT
Words containing more than 2 syllables.
syllables > 2
% COMPLEX WORDS
Proportion of complex words in total word count.
complex / total
FOG INDEX
Gunning Fog readability grade level. Higher = harder to read.
0.4 × (ASL + %CW)
WORD COUNT
Cleaned word count — stopwords and punctuation removed.
tokens − stopwords
SYLLABLE PER WORD
Average syllables across all words. Vowel-counting method.
Σ syllables / words
PERSONAL PRONOUNS
Count of I, we, my, ours, us. Country name "US" excluded via regex.
regex \b(I|we|my|ours|us)\b
AVG WORD LENGTH
Sum of all character counts divided by total word count.
Σ len(word) / words
AVG WORDS / SENTENCE
Same as average sentence length — included separately in output spec.
words / sentences
Code Architecture

Four files. Clean separation of concerns.

Each module does exactly one job. The architecture is deliberately modular — any module can be tested, swapped, or extended independently.

Stage 1 — Run First
🕷️
scraper.py

Web scraping engine. Uses requests.Session with full browser headers to avoid bot detection. Falls back across 4 CSS selectors for article body extraction. Logs failures to failed_urls.txt. Adds 1s delay between requests.

IN Input.xlsx
OUT articles/*.txt
requests beautifulsoup4 pandas
Module — Imported by main.py
🧠
sentiment.py

Loads all 7 stopword files and both word lists once at module level — not on every call. Tokenizes text, strips punctuation, removes stopwords, then scores against positive/negative dictionaries. Returns 4 scores as a dict.

IN article text
OUT 4 scores (dict)
nltk 7 stopword files master dictionary
Module — Imported by main.py
📐
readability.py

Combines NLTK stopwords with custom stopword files. Computes Gunning Fog index, syllable counts (with es/ed exception handling), personal pronoun regex (excludes country name US), and 6 other metrics.

IN article text
OUT 9 metrics (dict)
nltk re Gunning Fog
Stage 2 — Run Second
⚡
main.py

Pipeline orchestrator. Reads Input.xlsx, resolves each article file path, calls both analysis modules, builds a list of 15-value rows, constructs the output DataFrame once at the end (O(n) not O(n²)), and writes to Excel.

IN Input.xlsx + articles/
OUT Output.xlsx
pandas openpyxl os
